Bloxd Seed Map (default texture pack)
=====================================
1. Unzip this folder.
2. Double-click index.html (Chrome, Edge or Firefox).
3. Type a seed, press LOAD.

Chests: every structure with chests shows a chest icon outlined by its highest tier
(T1 white, T2 green, T3 blue, T4 purple, T5 yellow). Click one for the exact loot,
or type an item in "Find item in chests". Zoom in to see each chest separately.

Keep index.html, game_worker.js and textures.js in the same folder.
game_worker.js is Bloxd's world-generation code and textures.js holds default
texture pack images, both taken from files you supplied. Personal use only:
don't publish or redistribute this folder.
